# Glossary — TIRD

**Project:** EAV-TIRD-001

| Term | Definition in TIRD |
| :--- | :--- |
| **Isospatial** | Same spacetime coordinate. Multiple layers share every spacetime coordinate. |
| **Reflexive** | Mirror relation. Each layer is the mirror of its counterpart under operator R. |
| **Layer (H_k)** | One frequency-stratified component of the total Hilbert space, occupying the same spacetime support. |
| **Shared Quantum Space (Q)** | The single quantum space containing all layers. |
| **Frequency Band (B_k)** | The frequency range characterizing layer k. |
| **Native Frequency (omega_O)** | The central frequency of observer O. |
| **Bandwidth (sigma_O)** | Width of observer's perception window. |
| **Perception Kernel (G)** | Gaussian coupling: exp[-(omega_k - omega_O)^2 / 2 sigma_O^2]. Near zero = invisible. |
| **Portal** | Not a doorway. A resonance condition where G crosses detection threshold at same coordinates. |
| **Dwell-Time Cost (C)** | Cost of sustained presence: C = C_0 * (e^(tau / tau_c) - 1). |
| **Critical Disturbance (D_crit)** | Threshold where layer dynamical structure is progressively disrupted. |
| **Mirror Operator (R)** | Operator that reverses index order. R S = S for palindromic S. |
| **Palindromic Sequence** | Sequence reading identically forward and backward. Example: 1-2-3-3-2-1. |
| **Observer-Relative Time** | Time as index on shared manifold. Each observer has offset theta_O. t_A = t_B + kappa * (omega_A - omega_B). |
| **Effective Velocity (v_eff)** | v = c / (n + eta_O + eta_X + eta_I). Vacuum c remains constant. |
| **Information Correction (eta_I)** | Correction depending on Shannon entropy H of transmitted stream. |
| **Inter-Layer Coupling (J_ab)** | J_0 * G * exp(-D / D_crit). Strength of entanglement between layers. |
| **CHSH Parameter (S)** | Bell test correlator. <=2 local, <=2*sqrt(2) quantum. |
| **Integrated Information (Phi)** | Measure of consciousness from causal structure. TIRD predicts Phi correlates with perception-window width. |
| **Memory Integration (M)** | Weighted sum of inner products between elements and their mirrors. Maximal for palindromic sequences. |
| **Push-Pull** | Two distinct dimensions stacked at same coordinate, not binary opposites. Ratio = 1 at balance. |
| **On-Off Gate** | Coupling active only above threshold. Hysteresis width is measurable. |
| **Curvature** | Concave / convex local geometry as distinct dimensional aspects of same support. |
| **Frame Recurrence** | Periodic return of frames implied by reflexive sequence. |
| **Projection / Alignment** | Projection maps internal state onto external layer. Alignment is match under R. |
| **Dark Matter (in TIRD)** | Matter content of layers with near-zero perception kernel for ordinary observers. Hypothesis only. |
